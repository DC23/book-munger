### TDD notes

One cycle required a test fix rather than an implementation fix: `test_process_known_sentence` was initially written as `"Dogs run."` — `en_core_web_sm` tags a sentence-initial capitalised bare noun as `PROPN` (lemma `"dogs"`, not `"dog"`). Changed to `"The dogs run."` to give the model unambiguous context. The determiner resolves the NOUN/PROPN ambiguity. All other tests passed green on first implementation.

### Caching approach

`lru_cache` on `_load_model` was chosen over a module-level `_nlp = None` global because it handles multiple model strings correctly and exposes `cache_info()` for clean testability without monkeypatching. The test clears the cache, calls `process()` twice, and asserts `misses == 1, hits == 1`.
